# 문제 은행

## 구조
- bank(cat, diff 1~3, type, q, opts, answer, note, host, topic, media, used, pack, flagged). unique(q, media) — 노래 문제는 문제 글이 같으므로.
- pack: 청중별 묶음. boss(40~50대 회식) | peer(94~00년생 동기) | all(공통, 예: 2000년대 후반 이후 노래). 진행자가 랜덤 뽑기/은행 둘러보기에서 묶음을 고르고 폰에 기억, compose 가 state.pack 에 저장해 문제 교체도 같은 묶음에서.
- compose: 카테고리별 개수를 받아 used 적은 순 + 랜덤, 같은 topic 은 한 세트에 하나만(비슷한 문제 두 개는 topic 을 같게). pinned(사진 등) 유지.
- 생성 스크립트(app/db/bank_gen.py + peer_questions.py)로 04_bank.sql 을 만들고 upsert. 뺀 문제는 "pack 의 현재 목록에 없는 q 삭제" SQL 을 같이 돌린다.

## 카테고리
- boss: 추억(80~90년대)·가요·노래·요즘 말·예능·이모지·회사·상식·다수결·소수결·베팅
- peer: 인물(요즘 유튜버·예능인·역주행 아이돌)·트렌드(캐릭터·디저트·밈·OTT)·요즘 말(최신 유행어)·학창시절·게임(국민 게임만)·추억(2000~10년대)·가요(2세대 아이돌)·예능·이모지·회사(신입 생활)·다수결·소수결·베팅

## 난이도·균형 (실제 피드백에서 배운 것)
- 기준: "그 세대면 대부분 들어 봤지만 바로 튀어나오진 않는 것".
- 너무 어려움 → 뺀다: 축구 경기 결과, 게임 디테일(메소·종족·출시 연도·개발사), 애니 디테일(디지몬·탑블레이드), 팬덤만 아는 것(데뷔곡·발매 연도·캐릭터 친구).
- 너무 쉬움 → 뺀다: 문제만 읽어도 답이 보이는 것(야동순재, 야자 뜻, ㅇㅈ, 보기 중 하나만 엉뚱한 것).
- 남녀 모두 맞힐 수 있게: 게임·스포츠·아이돌·캐릭터는 "이름은 다 들어 봤다" 수준까지만. 나혼산·흑백요리사·케데헌·올영세일·환승연애처럼 함께 본 소재 위주.
- 최신 유행어·인물은 기억 말고 웹 검색으로 뜻과 사실을 확인한 뒤 넣고, 출처가 엇갈리면 그 점을 사용자에게 말한다. 누군지 확인 안 되는 인물은 넣지 않는다.
- 인물 사진 문제는 저작권 때문에 만들지 않고, 사용자가 직접 고른 사진을 붙이게 안내.

## 형식
- 한 판 12~16문제, 15초. 해설 한 줄, 출처 문구 없음. 보기 길이 비슷하게, 정답 위치 섞기(생성기에서 shuffle).
- 노래: 공식 오디오 링크만. 못 찾으면 그 곡은 공식 음원이 있는 다른 곡으로 대체. 유튜브는 샌드박스에서 막혀 있으니 재생 확인은 사용자에게 부탁.

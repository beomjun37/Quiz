# 문제 은행

- bank(cat, diff 1~3, type, q, opts, answer, note, host, topic, media, used). unique(q, media) — 노래 문제는 문제 글이 같으므로.
- compose: 카테고리별 개수를 받아 used 적은 순 + 랜덤으로 뽑고, 같은 topic은 한 세트에 하나만. pinned 문제(사진 등 직접 만든 것)는 유지.
- 생성 스크립트(python)로 04_bank.sql을 만들고, 재실행해도 안전하게 upsert + 빠진 문제만 삭제.
- 30~50대 회식에서 반응 좋았던 것: 추억(90~00년대), 예능 명장면, 요즘 말 뜻 맞히기, 이모지 드라마, 노래 첫 소절, 다수결("100명에게 물었습니다"), 소수결, 베팅 문제.
- 피할 것: 상사·특정 동료 저격, 2차/음주 강요, 주관식(폰 입력이 느리고 채점 분쟁).
- 한 판은 12~16문제, 15초 제한이 적당. 해설(note)은 한 줄, 출처 문구는 넣지 않는다.
- 문구는 쉬운 구어체로, 보기 길이를 비슷하게, 정답 위치를 고르게 분산.

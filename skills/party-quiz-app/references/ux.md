# 진행자/참가자 UX 패턴 (iOS 느낌)

- 진행자는 하단 탭 3개(진행/문제/설정). 큰 제목 + 오른쪽 ⋯ 버튼, 부가 도구는 액션시트 → 페이지 시트.
- confirm() 대신 Promise 기반 액션시트 `ask(msg,{ok,danger})`. 페이지 시트 위에 뜨도록 z-index를 한 단계 높게(실제로 가려졌던 버그).
- 오류는 영어 원문 대신 코드→한국어 문장 매핑, 알 수 없는 오류엔 "다시 시도" 버튼.
- 문항 편집은 목록(번호·유형·태그·›) → 탭 → 상세 편집(이전/다음, ← 목록).
- 참가자: 닉네임 자동 추천(유치하지 않게), 답 선택은 큰 버튼, 정답 공개 시 내 답/정답 배지, 순위 변동 표시, 리액션 이모지, 전체 순위 시트.
- 화면 꺼짐 방지(Wake Lock), 재접속 시 저장된 id로 자동 복귀, 세션이 리셋되면 깔끔하게 로그아웃.
- 진행자 폰에 타이머·응답 수·다음 버튼을 크게. 실수 대비 "되돌리기"와 "문제 건너뛰기".
- 연습 모드(#/sim): 봇과 혼자 끝까지 돌려 보는 리허설.
